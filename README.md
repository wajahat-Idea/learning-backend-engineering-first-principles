## What is backend engineering from first principles?

Backend engineering from first principles means breaking server-side systems
down to their fundamental constraints (CPU, memory, disk, and network) and
rebuilding your understanding from there. Instead of memorizing framework
APIs, you learn the underlying ideas, so the skills transfer across any
language or stack.

## FAQ

### What will I learn in this series?
How backend systems work end to end: networking, HTTP, databases, caching,
concurrency, APIs, and system design, with working code for each concept.

### Do I need prior backend experience?
No. Basic programming knowledge is enough. Each topic starts with the problem
it solves before getting into implementation.

### Which language is used?
[Your language(s)]. The concepts are language-agnostic, so you can apply them
in any stack.

### How is this different from a framework tutorial?
Framework tutorials teach tools. This series teaches the principles those
tools are built on, so you can learn any new tool faster.
